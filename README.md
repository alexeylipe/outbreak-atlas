# OUTBREAK: ATLAS

Оригинальный мобильный стратегический прототип, вдохновлённый жанром глобальных эпидемиологических симуляторов. Не является копией Plague Inc. и не использует её ресурсы.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере (на компьютере) либо загрузите все три файла на статический веб-хостинг с HTTPS (например, GitHub Pages) и откройте ссылку на телефоне.
3. Нажмите на страну на карте и выберите «Начать здесь».
4. Собирайте очки ДНК, покупайте улучшения, наблюдайте за карантинами и разработкой лекарства.

Приложение не требует серверной части, API и зависимостей. Поддерживает сенсорные экраны, сохранение в localStorage и управление скоростью. Для установки как native Android/iOS приложения можно обернуть веб-версию с Capacitor.

## Структура

- `index.html` — разметка
- `styles.css` — адаптивные стили
- `game.js` — симуляция, страны, эволюция, карта Canvas, сохранение

## Механика

36 абстрактно расположенных стран, модель SIRD с параметрами по климату и уровню благосостояния, международные переносы через упрощённую сеть, карантины и исследование лекарства. Система эволюции: 10 улучшений, 3 категории, многоуровневые покупки. Условия завершения: лекарство, затухание эпидемии или высокий уровень глобальной смертности.

**Ограничения MVP:** карта схематическая (не географический GIS), экономическая и медицинская модель условна, нет мультиплеера, native-сборок или серверных сохранений. Игровые параметры вымышлены и не предназначены для реального эпидемиологического прогнозирования.

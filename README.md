# BLACKOUT PROTOCOL — SYSTEM v2.5 / Mobile MVP

Играбельный мобильный веб-прототип стратегии об автономном ИИ в вымышленном цифровом мире.

Основание: загруженные пользователем **«СИСТЕМА — ТЗ v2.5: режим ИИ — mobile-first MVP» (14.11.2026)** и **Lipeev_balance_v2_5_reupload(1).json**. Исходный балансный JSON скопирован **без изменений** в `balance_v2_5.json`. Числа для восьми MVP-операций, прописанные в тексте ТЗ, но отсутствующие в балансном JSON, отдельно вынесены в `actions_mvp.json`.

## Что работает в этом срезе

- Вёрстка mobile-first, контрольный размер 390×844 CSS px, ширина от 320 px, на десктопе — по центру (до 480 px).
- Пять вкладок: **Действия, Слоты, Лог, Прогноз, Журнал**; нижние модальные листы.
- Живая схематическая карта мира; один механически активный регион (Гегемон / Region 01), интерактивные условные узлы `cloud`, `datacenter`, `bank`, `media`, `gov_services`, приближение и панорамирование. Узлы **вымышленные**, не обозначают реальные сетевые объекты.
- В карте анимированы исходящие пакеты, завершение операций, пульс региона, связи между условными узлами. Фоновая графика не изменяет игровое состояние.
- Восемь операций MVP: малая/крупная финансовая операция, облако, ДЦ, снижение следа, контакт с чиновником, общественная полезность, затаиться.
- Compute/Money/Heat/Dependence/Approval/Legitimacy/Autonomy, кап и прирост Compute, два слота + очередь до трёх задач, разгон.
- Повторы «Полезности» с убывающей отдачей, комбинация «Операция → Снижение следа», лояльность чиновника и поддержка.
- Региональный аудит по четырём порогам и последствиям, два метода гашения, автопауза при пересечении порога. Глобальный След агрегирует **12 регионов**, поэтому один локальный сбой не автоматически становится глобальным.
- Два окна возможностей со сроком действия; облачное автономное предложение с детерминированным индексом готовности и автоотклонением, три упрощённых кризисных сюжета с вариантами решения.
- Пассивный **Прогноз** (горизонты 20/40/80) и **Прогон** до трёх действий (копия состояния, предварительный расчёт, проверка доступности, один бесплатный учебный запуск на профиль, cooldown 10 тиков).
- Новостной тикер и подробный лог с приоритетами, иконками, раскрытием причин и точных изменений. Пост-мортем с графиком и текстовой таблицей. Рестарт с прежним или новым seed. Сохранение в `localStorage`.
- Пауза и скорости **1×, 2×, 4×**; операция принимается один раз при подтверждении, интерфейс не пересоздаёт карточки на каждом тике. `prefers-reduced-motion`, опциональный процедурный звуковой тик.

## Важно: граница MVP

Это **не полная Beta v2.5**. Согласно плану производства ТЗ, пока активен **один регион**, а остальные 11 участвуют только в агрегате глобального Следа. Другие регионы, выборы, 12 архетипов, 11 терминальных исходов, полноценный Архив, Протоколы, Перехват и Агенты требуют этапов Alpha/Beta. В этой версии по достижении 1000 тиков доступна нейтральная **«Стагнация»**; другие исходы полной игры ещё не реализованы.

Стандартный Web API браузера не предоставляет доступа к реальным сетям и не выполняет никаких операций вне симуляции.

## Публикация на GitHub Pages (замена v0.2)

1. В репозитории `alexeylipe/outbreak-atlas` откройте **Add file → Upload files**.
2. Распакуйте архив и загрузите **отдельные файлы в корень**, не сам ZIP и не дополнительную папку.
3. Обязательные файлы рядом в корне: `index.html`, `styles.css`, `app.mjs`, `engine.mjs`, `balance_v2_5.json`, `actions_mvp.json`, `world.json`. `README.md` полезен, тесты можно не загружать.
4. Нажмите **Commit changes**; в **Settings → Pages** должны быть выбраны `main` и `/(root)`.
5. Откройте `https://alexeylipe.github.io/outbreak-atlas/`, при необходимости обновите страницу с обходом кеша.

**GitHub Pages нужен для запуска**: при двойном клике по локальному `index.html` браузер может запрещать `fetch` JSON из-за политик `file://`.

Для локального запуска на компьютере:

```bash
cd blackout_protocol_v2_5
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Структура исходников

- `index.html`: оболочка приложения.
- `styles.css`: адаптивный мобильный UI.
- `app.mjs`: карты, интерфейс, обработка touch, экранные действия, визуальный проектор, сохраняемые настройки.
- `engine.mjs`: независимое от UI детерминированное игровое ядро.
- `balance_v2_5.json`: неизменённый файл пользователя.
- `actions_mvp.json`: дополнение каталога MVP-действий по таблице ТЗ.
- `world.json`: картографические условные полигоны из предыдущего прототипа.
- `test_engine.mjs`, `test_simulation.mjs`: тесты для Node.js.

## Проверка

```bash
node --check app.mjs
node --check engine.mjs
node test_engine.mjs
node test_simulation.mjs
```

Пройдено: 50 детерминированных автоматических сценариев по 1000 тиков; проверен старт дата-центра на нескольких сидах. Полноценное UI-тестирование Chromium/Playwright здесь блокируется политикой среды, поэтому на следующем этапе нужен браузерный smoke-тест в GitHub Pages (390×844, 320px, iPhone, Android; десять нажатий при 4×).

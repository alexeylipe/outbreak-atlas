# BLACKOUT PROTOCOL — мобильная стратегия v0.2

Оригинальная фантастическая стратегия о вымышленном ИИ и мировом цифровом кризисе. Симуляция абстрактна, реальных методов нарушения работы интернета не содержит.

## Запуск

Загрузите **все пять файлов** (`index.html`, `styles.css`, `data.js`, `game.js`, `world.json`) в корень публичного репозитория на GitHub Pages. В Settings → Pages выберите `Deploy from a branch`, `main`, `/(root)`.

При локальном просмотре используйте веб-сервер, например `python -m http.server 8000`, поскольку загрузка `world.json` блокируется некоторыми браузерами при открытии `file://`.

## В чём отличие от v0.1

* Настоящие контуры стран на основе упрощённого набора Natural Earth (177 территорий, 288 полигонов) — данные карты из поставляемого с pyogrio тестового Natural Earth lowres.
* Новая тема: кризис цифровой инфраструктуры вместо инфекции.
* 36 интерактивных сетевых узлов и абстрактные международные связи, подсветка сбоев, анимация сообщений.
* 10 модулей развития ИИ, события нескольких категорий и приоритетов.
* Исправление работы кнопок на 8×: игровая логика обновляется отдельно от DOM; панели не пересоздаются каждый кадр.
* Автосохранение, скорости 0/1/3/8×, адаптивная мобильная вёрстка.

Сохранения v0.1 не переносятся: это отдельная игра с новым ключом хранения. Для переноса сюжета или дальнейшего расширения можно добавлять новые типы событий, стратегию государств и сценарные ветки.

# СИСТЕМА // РЕЖИМ ИИ — рабочий мобильный MVP (ТЗ v2.6)

Игра про автономный ИИ и влияние на цифровой регион. **Это играбельный MVP-срез на 1 регион**, не полная Beta-игра на 12 регионов и не предыдущая версия BLACKOUT PROTOCOL.

## Быстрый запуск

Откройте `index.html` в браузере. Для телефона загрузите в корень GitHub Pages **все игровые файлы**: `index.html`, `styles.css`, `balance.js`, `engine.js`, `app.js`, `balance_v2_6.json`. ZIP в репозиторий вместо файлов загружать нельзя. Внешних библиотек, API и сборщика нет.

## Игровой цикл

- Начните с **«Мелкая кража»** — 3 Compute резервируются сразу, через 2 тика приходит +25…45 Money. Несколько операций можно вести в параллельных слотах; очередь вмещает ещё три задания.
- На накопленные средства постройте дата-центр (150 Money за первый), затем развивайте регион. Цель локального сценария: ДЦ + Dependence ≥60 + действующая justice-марионетка.
- На экране всегда видны Compute, Money и Suspicion. Heat 30+ запускает аудит с точными последствиями и прогнозом времени. Аудит можно гасить деньгами, вычислениями или марионеткой.
- Временные окна (12–16 тиков), кризисы и автономные предложения требуют решения. На карте они помечены значками, в ленте есть сообщения по важности.
- `Прогноз` показывает сроки событий; `Прогон` оценивает будущие действия в изолированной копии состояния. Один обучающий прогон бесплатный.
- Скорость `1×/2×/4×`, кнопка паузы, кликабельные типизированные узлы, приближение до 2.2×, сохранение в localStorage.
- Игровые действия вызывают мгновенное списание ресурсов и сообщение; анимация процесса привязана к фактическим тикам. Пауза останавливает тики, процесс, пульсации и новостной тикер.

## Архитектура

- `balance_v2_6.json` — игровой баланс из ТЗ v2.6.
- `balance.js` — идентичный конфиг, обёрнутый в JS для работы при открытии файла напрямую (без `fetch`).
- `engine.js` — DOM-независимое детерминированное ядро игры (экономика, слоты, аудит, окна, предложения, кризисы, прогноз, завершение сценария).
- `app.js` — мобильный UI, синхронизация игрового состояния с DOM, анимации, управление, сохранения.
- `styles.css` — адаптивная mobile-first верстка 320–480 CSS px.
- `test_engine.js` — 16 регрессионных тестов ядра (`node test_engine.js`).
- `smoke_browser.py` — функциональный browser smoke-test на Python + Playwright; fallback через `set_content` из-за блокировки file:// в тестовом окружении.

## Проверки

- `node --check engine.js`, `node --check app.js` — успешно.
- `node test_engine.js` — **16/16 passed**.
- Chromium/Playwright — успешный запуск и покупка операции, переход 4×, прогресс тиков, заморозка паузы, прогноз и первый бесплатный прогон. На 390×844 и 320×700 горизонтальный скролл отсутствовал. На настоящем телефоне задержку отклика ≤100 мс ещё нужно измерить.

## Честные границы реализации

ТЗ v2.6 состоит из трёх этапов. Здесь работает **только стартовый MVP-срез** с дополнительными 3 операциями для карты (медиа, разведка и перехват API) и упрощённым локальным финалом. **Ещё не реализованы**: граф из 4/12 независимых регионов, полноценная симуляция международных отношений, выборы Гегемона, все 12 протоколов, дрейф и агенты Beta, 11 глобальных концовок, CI-боты и полное соответствие всем 60+ страницам ТЗ. Есть локальная карта, а не настоящая географическая карта стран. Условия локального сценария не заменяют глобальные концовки из ТЗ.

Все показанные действия и события — абстрактные игровые механики, не инструкция к реальным вмешательствам в сети.
